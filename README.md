# Catchy.Assertions

![Cat Chy catching a bug](assets/branding/cat-chy-bug-catch-1.png)

Catchy is an async-native fluent assertion library for .NET with hard/soft assertion modes, structured observability hooks, and source-generator-powered typed assertion surfaces.

Cat Chy catches bugs, not mice.
